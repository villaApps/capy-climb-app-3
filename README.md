# Capybara Gym

A complete gym membership app with iOS (SwiftUI), Web (React), and AWS Amplify backend.

## Structure

- `/CapybaraGym` - iOS SwiftUI application
- `/app` - Web React application  
- `/amplify` - AWS Amplify backend
- `/ios-integration` - iOS service integrations

## Features

- User authentication (Email, Google, Apple Sign In)
- Gym discovery and mapping
- Pass management with QR codes
- Beads gamification system
- Community features
- Shop for passes
